## ✨ Key Features

### 🖨️ Direct Printer & Scanner Integration
Connect directly to your scanner and import documents straight into the workspace — no third-party utilities required.
- **Flatbed and ADF** source selection with **simplex and duplex** support.
- **Auto / A4 / A5 / A6 / B5 / Letter / Legal / Executive** paper sizing.
- Adjustable **DPI** from 75 up to 1200.
- **Color**, **Grayscale**, and **Black & White** capture modes.
- **Portrait** and **Landscape** orientation.
- **Live preview** before adding scanned pages to your document.

### 📑 Advanced Document Organization (Organize Pages)
A dedicated full-grid page manager to keep large documents under control.
- **Rearrange** pages with intuitive drag-and-drop.
- **Multi-select** with Ctrl+Click and Shift+Click.
- **Rotate**, **delete**, and **export** selected pages only.
- **Export** to images or a single multi-page PDF.
- Send selected pages straight to **print**.
- **Zoom slider** for thumbnail density — remembers your preference.
- Double-click any page to open it in the main editor.

### ☁️ Premium Cloud AI Processing
Optional cloud AI enhancement for the most demanding documents.
- Choose from supported cloud AI providers.
- Configure your own model and API key.
- Send **full-resolution** images when you need the best results.
- **One-time privacy consent** — revoked automatically if you change provider or key.
- **Automatic local fallback** if the cloud request fails, so you never lose work.

### 🖼️ Universal Image Format Support
Import virtually any image format without conversion.
- Modern formats from iPhone and modern Android (**HEIC / HEIF / AVIF**).
- All common formats (**JPG, PNG, WebP, BMP, TIFF, GIF**, and more).
- **Automatic photo-orientation** correction.
- **Full multi-page PDF** import and re-export.

### 🔍 Precise Edge Detection
Accurately detects paper boundaries even against noisy, cluttered, or low-contrast surfaces.

### 🧲 Magnetic Snap Crop & Auto-Deskew
- **Smart corner snapping** locks onto document edges while you drag.
- **Full 90° rotations**.
- **Fixed aspect-ratio templates** with an independent **Flip / Unflip** orientation toggle.
- **Accurate perspective correction** for angled captures.

### ☀️ Automatic Shadow Removal
Eliminates finger, hand, and camera shadows — without distorting text or introducing halos.

### 🎨 Six Enhancement Modes
| Mode | Best for |
|------|----------|
| **Magic Color** | Everyday documents — natural color with balanced contrast |
| **Original** | Untouched capture with only user-applied adjustments |
| **B&W Adaptive** | Crisp black-and-white text |
| **Sauvola Adaptive** | Dark, solid text on low-contrast or aged paper |
| **Ultra White Pro** | Clean white backgrounds with subtle color retention |
| **Ultra Magic White** | Aggressive scan look — pure white paper, deep black ink |

Plus **unlimited user-defined presets**, saved with a single click and reapplied to any batch.

### 🚀 High-Speed PDF Export
- **Import PDF pages** and re-export multi-page scan collections into crystal-clear PDF files.
- **Optimal compression** for small file sizes without visible quality loss.
- **Selected-pages-only** export from the Organize Pages window.
- Automatically opens the resulting PDF in your default viewer.

### 🖨️ Printing
- **Print the current page** or **all pages** with one click.
- Batch printing handles multi-page documents.
- Selected-pages printing always follows document order.

### 📋 Easy Import Workflow
- **Drag & drop** images and PDFs directly into the workspace.
- **"Open with" support** — files passed from Windows Explorer are ingested automatically.

### ⚙️ Custom Configuration & Presets
- Save preferred parameter combinations as reusable presets.
- Set your favourite settings as the defaults applied to every new page.
- **One-click factory reset** to restore original settings.

### 🌍 Internationalization
- Full **English** and **العربية** (Arabic) interface.
- Switch languages at any time — every label, dialog, and status message updates instantly.

### 🎭 Appearance
- **Dark & Light** themes with live switching.
- **Text-size scaling** (Small / Medium / Large).

### 👤 Account Management
- **Sign in with Google**.
- **Device-bound licensing**.
- Manage linked devices and unlink them from the app.
- Redeem activation keys directly from the Settings window.
- Live **licence status** — expiry date, days remaining, and active/expired indicator.
- Keeps working offline using a securely cached licence.

### 🔄 Built-in Auto-Updater
- Checks for new versions on demand.
- Shows **release notes** before downloading.
- **Background download** with a progress bar.
- **Silent installation** and automatic relaunch.

### 🔐 Security & Integrity
- **Cryptographically signed licences** — tampered or forged tokens are rejected at startup.
- **Invisible per-licence watermark** embedded in every saved or exported image.

### ⌨️ Keyboard Shortcuts
| Shortcut | Action |
|----------|--------|
| `←` / `→` | Previous / Next page |
| `↑` / `↓` | Move page up / down |
| `R` / `L` | Rotate 90° CW / CCW |
| `Del` | Remove current page |
| `Esc` | Fit view / reset zoom |
| `Ctrl+S` | Save current page |
| `Ctrl+H` / `Ctrl+P` | Print current page |
| `Ctrl+O` | Open Organize Pages |
| `Enter` | Apply crop & rotation |
