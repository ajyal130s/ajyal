# 📄 Ajyal Scanner Pro

A sophisticated desktop application designed to process and enhance document images and documents with high precision and speed — powered by programmatic edge detection and classical computer vision.

---

## ✨ Key Features

* 🔍 **Multi-Pass Edge Detection**  
  Multi-pass edge filtering using adaptive thresholding and morphological gradients ensures exact paper boundary detection even against noisy surfaces.

* 🧲 **Magnetic Snap Crop**  
  Smart corner snapping automatically locks onto high-contrast document edges when dragging handles, preventing manual positioning errors.

* ☀️ **Top-Hat Shadow Removal**  
  Eliminates finger, hand, and camera shadows via Top-Hat & Black-Hat morphological operations within the LAB color space without distorting text.

* 🚀 **High-Speed PDF Export**  
  Seamlessly import PDF pages and re-export multi-page scan collections into crystal-clear PDF files with optimal compression.

* ⚙️ **Custom Configuration Presets**  
  Save your preferred scan parameter combinations (contrast, block size, sharpening) and re-apply them to any batch with a single click.

* 📐 **Auto-Deskew & Aspect Ratios**  
  Full 90° rotations while maintaining coordinate memory, plus fixed aspect ratio templates (A4, US Letter, ID Cards, Square).
