## ✨ الميزات الرئيسية

### 🖨️ تكامل مباشر مع الطابعة والماسح الضوئي
اتصل مباشرة بالماسح الضوئي واستورد المستندات إلى مساحة العمل — دون الحاجة إلى أدوات طرف ثالث.
- اختيار المصدر **المسطحة (Flatbed) و ADF** مع دعم **البسيط (Simplex) والمزدوج (Duplex)**.
- أحجام ورق **Auto / A4 / A5 / A6 / B5 / Letter / Legal / Executive**.
- **DPI** قابل للتعديل من 75 إلى 1200.
- أوضاع الالتقاط: **ملون**، **رمادي**، و**أبيض وأسود**.
- اتجاه **عمودي** و**أفقي**.
- **معاينة مباشرة** قبل إضافة الصفحات الممسوحة ضوئيًا إلى المستند.

### 📑 تنظيم متقدم للمستندات (تنظيم الصفحات)
مدير صفحات كامل بشبكة مخصصة لإبقاء المستندات الكبيرة تحت السيطرة.
- **إعادة ترتيب** الصفحات بواسطة السحب والإفلات.
- **تحديد متعدد** باستخدام Ctrl+Click و Shift+Click.
- **تدوير**، **حذف**، و**تصدير** الصفحات المحددة فقط.
- **تصدير** إلى صور أو ملف PDF واحد متعدد الصفحات.
- إرسال الصفحات المحددة مباشرة إلى **الطباعة**.
- **شريط تمرير التكبير/التصغير** لكثافة الصور المصغرة — يتذكر تفضيلاتك.
- انقر نقرًا مزدوجًا على أي صفحة لفتحها في المحرر الرئيسي.

### ☁️ معالجة سحابية بالذكاء الاصطناعي (Premium)
تحسين سحابي اختياري بالذكاء الاصطناعي لأكثر المستندات تعقيدًا.
- اختر من بين مزودي الذكاء الاصطناعي السحابي المدعومين.
- قم بتهيئة النموذج ومفتاح API الخاصين بك.
- أرسل صورًا **بدقة كاملة** عندما تحتاج إلى أفضل النتائج.
- **موافقة خصوصية لمرة واحدة** — تُلغى تلقائيًا إذا غيّرت المزود أو المفتاح.
- **تراجع محلي تلقائي** إذا فشل طلب السحابة، حتى لا تفقد عملك أبدًا.

### 🖼️ دعم شامل لتنسيقات الصور
استورد أي تنسيق صورة تقريبًا دون تحويل.
- تنسيقات حديثة من iPhone وأندرويد الحديث (**HEIC / HEIF / AVIF**).
- جميع التنسيقات الشائعة (**JPG، PNG، WebP، BMP، TIFF، GIF**، والمزيد).
- **تصحيح تلقائي لاتجاه الصورة**.
- **استيراد وتصدير كامل لملفات PDF متعددة الصفحات**.

### 🔍 كشف دقيق للحواف
يكتشف حدود الورق بدقة حتى على الأسطح المزعجة أو المزدحمة أو منخفضة التباين.

### 🧲 قص مغناطيسي وتصحيح تلقائي للميل
- **التقاط ذكي للزوايا** يثبت على حواف المستند أثناء السحب.
- **دورانات كاملة بزاوية 90°**.
- **قوالب بنسبة أبعاد ثابتة** مع مفتاح تبديل اتجاه **قلب / إلغاء القلب** مستقل.
- **تصحيح دقيق للمنظور** للالتقاطات المائلة.

### ☀️ إزالة تلقائية للظلال
يزيل ظلال الأصابع واليد والكاميرا — دون تشويه النص أو إحداث هالات.

### 🎨 ستة أوضاع للتحسين
| الوضع | الأنسب لـ |
|------|----------|
| **Magic Color** | المستندات اليومية — ألوان طبيعية مع تباين متوازن |
| **Original** | الالتقاط الأصلي دون تعديل مع التعديلات التي يطبقها المستخدم فقط |
| **B&W Adaptive** | نص أبيض وأسود واضح |
| **Sauvola Adaptive** | نص داكن وصلب على ورق منخفض التباين أو قديم |
| **Ultra White Pro** | خلفيات بيضاء نظيفة مع احتفاظ طفيف بالألوان |
| **Ultra Magic White** | مظهر مسح ضوئي قوي — ورق أبيض نقي وحبر أسود عميق |

بالإضافة إلى **إعدادات مسبقة غير محدودة من إنشاء المستخدم**، تُحفظ بنقرة واحدة وتُعاد تطبيقها على أي دفعة.

### 🚀 تصدير PDF عالي السرعة
- **استيراد صفحات PDF** وإعادة تصدير مجموعات المسح متعددة الصفحات إلى ملفات PDF فائقة الوضوح.
- **ضغط مثالي** لأحجام ملفات صغيرة دون فقدان جودة مرئي.
- **تصدير الصفحات المحددة فقط** من نافذة تنظيم الصفحات.
- يفتح ملف PDF الناتج تلقائيًا في العارض الافتراضي.

### 🖨️ الطباعة
- **طباعة الصفحة الحالية** أو **كل الصفحات** بنقرة واحدة.
- طباعة الدفعات تتعامل مع المستندات متعددة الصفحات.
- طباعة الصفحات المحددة تتبع دائمًا ترتيب المستند.

### 📋 سير عمل استيراد سهل
- **السحب والإفلات** للصور وملفات PDF مباشرة إلى مساحة العمل.
- **دعم "فتح باستخدام"** — تُستورد الملفات القادمة من مستكشف Windows تلقائيًا.

### ⚙️ تهيئة مخصصة وإعدادات مسبقة
- احفظ مجموعات المعلمات المفضلة كإعدادات مسبقة قابلة لإعادة الاستخدام.
- عيّن إعداداتك المفضلة كافتراضية تُطبق على كل صفحة جديدة.
- **إعادة ضبط المصنع بنقرة واحدة** لاستعادة الإعدادات الأصلية.

### 🌍 التدويل
- واجهة كاملة باللغتين **الإنجليزية** و**العربية**.
- بدّل اللغات في أي وقت — يتم تحديث كل تسمية ومربع حوار ورسالة حالة فورًا.

### 🎭 المظهر
- سمتان **داكنة وفاتحة** مع تبديل مباشر.
- **تحجيم حجم النص** (صغير / متوسط / كبير).

### 👤 إدارة الحساب
- **تسجيل الدخول باستخدام Google**.
- **ترخيص مرتبط بالجهاز**.
- إدارة الأجهزة المرتبطة وإلغاء ربطها من التطبيق.
- استرداد مفاتيح التنشيط مباشرة من نافذة الإعدادات.
- **حالة ترخيص مباشرة** — تاريخ الانتهاء، الأيام المتبقية، ومؤشر نشط/منتهي.
- يستمر في العمل دون اتصال باستخدام ترخيص مخزن بشكل آمن.

### 🔄 محدّث تلقائي مدمج
- يتحقق من الإصدارات الجديدة عند الطلب.
- يعرض **ملاحظات الإصدار** قبل التنزيل.
- **تنزيل في الخلفية** مع شريط تقدم.
- **تثبيت صامت** وإعادة تشغيل تلقائية.

### 🔐 الأمان والسلامة
- **تراخيص موقعة تشفيريًا** — يتم رفض الرموز المتلاعب بها أو المزورة عند بدء التشغيل.
- **علامة مائية غير مرئية لكل ترخيص** مدمجة في كل صورة محفوظة أو مصدرة.

### ⌨️ اختصارات لوحة المفاتيح
| الاختصار | الإجراء |
|----------|--------|
| `←` / `→` | الصفحة السابقة / التالية |
| `↑` / `↓` | نقل الصفحة لأعلى / لأسفل |
| `R` / `L` | تدوير 90° في اتجاه عقارب الساعة / عكس عقارب الساعة |
| `Del` | إزالة الصفحة الحالية |
| `Esc` | ملاءمة العرض / إعادة ضبط التكبير |
| `Ctrl+S` | حفظ الصفحة الحالية |
| `Ctrl+H` / `Ctrl+P` | طباعة الصفحة الحالية |
| `Ctrl+O` | فتح تنظيم الصفحات |
| `Enter` | تطبيق القص والتدوير |

## 🛠️ الإصلاحات والتحسينات الأخيرة

- **السحب والإفلات** — تم حل مشكلات الاستيراد؛ أصبح الإدخال إلى مساحة العمل الرئيسية سلسًا وموثوقًا.
- **تصحيح المنظور** — تحسين الدقة لتقويم التقاطات المستندات المائلة.
- **إصلاح نسبة الأبعاد** — معالجة صحيحة لإعدادات A4، US Letter، بطاقة الهوية/العمل، والمربع مع مفتاح تبديل اتجاه مستقل.
- **أوضاع الأبيض والأسود** — تم تحسين `Ultra White Pro` و`Ultra Magic White` و`Sauvola Adaptive` لمنع احتراق النص وبهتان الخلفيات.
- **إزالة الظلال** — تم تحسينها لتجنب الهالات وتدهور النص.
- **تحديث الصور المصغرة** — تعكس الصور المصغرة في الشريط الجانبي وتنظيم الصفحات الآن التعديلات المباشرة والتدويرات وتغييرات نسبة الأبعاد دون الحاجة إلى تبديل الصفحة.
- **حفظ حالة النافذة** — تتذكر النافذة الرئيسية والإعدادات وتنظيم الصفحات ومربعات حوار الماسح الضوئي حجمها وموضعها وتكبيرها.
- **لوحة معلومات الحساب** — تتبع مدمج للتراخيص النشطة، مع عرض الأيام المتبقية والحالة مباشرة داخل واجهة الإعدادات.
